# Decisions — the learning log

How the stand-in gets better at *your* line. Every time you override a triage call or edit
a draft, it appends a short rule here, reads this file during triage, and applies the
rules. Newest at the top.

## Format

```
- [date] LANE-CHANGE: <item pattern> → move to lane <n>. Reason: <owner said ...>
- [date] VOICE: <what the owner changed in a draft> → prefer <...>
- [date] HIDE: always keep <pattern> in noise.
- [date] SURFACE: always bring <pattern> to me.
- [date] MODE: <how the owner wants the stand-in to operate>
```
